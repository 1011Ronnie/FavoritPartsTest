# Поиск автозапчастей

Клиент для API «Проценка» Favorit Parts: поиск производителей по артикулу, затем исходных товаров и аналогов с предложениями по каждому складу.

Стек: React, JavaScript, Redux Toolkit / RTK Query, Vite, Bootstrap CSS.
Описание внешнего API сохранено в [wsprice.md](./wsprice.md).

## Запуск

Нужны Node.js 22.13+ в ветке 22 либо Node.js 24+ (рекомендуется Node.js 24 LTS) и npm. Ограничение Node.js учитывает требования ESLint 10.

```sh
npm ci
cp .env.example .env
```

Укажите действующий ключ клиента в `.env`:

```dotenv
VITE_API_KEY=ваш-ключ
```

```sh
npm run dev
```

Откройте адрес, напечатанный Vite (обычно `http://localhost:5173`). После изменения `.env` перезапустите сервер. Без ключа приложение показывает инструкцию и не отправляет запросы.

## Использование

1. Введите артикул: через 400 мс после последнего изменения появится список производителей.
2. Выберите производителя: приложение запросит исходные товары и аналоги.
3. В таблице каждое предложение склада занимает отдельную строку. Цена и остаток берутся только из `warehouses`; поле цены самого товара не используется. Код склада при отсутствии заменяется его ID.

Товары без предложений остаются в таблице с пометкой «Нет в наличии». Нулевые цены и остатки отображаются как `0`, отсутствующие значения — как `—`. Валюта в документации API не определена, поэтому символ валюты не добавляется.

При смене артикула старые результаты, выбранный бренд и ошибки сразу скрываются. Текущие запросы отменяются; при смене производителя отменяется запрос его предложений. Загрузка не блокирует поле ввода и переключение брендов. После ошибки доступна кнопка повтора.
